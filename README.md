# marianacorrea.com.br

Portfólio de Mariana Corrêa — estrategista de marcas, designer e direção criativa.

Astro 7 (estático) · Tailwind CSS 4 · Lenis · GSAP

## Rodar

```bash
npm install
```

```bash
npm run dev
```

## Build

```bash
npm run build
```

Saída estática em `dist/`. Publique em qualquer host de arquivos estáticos
(Vercel, Netlify, Cloudflare Pages).
